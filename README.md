# 🛒 Sacolão da Generation & Revisão Python

Este repositório contém o desenvolvimento de uma aplicação interativa de console em **Python** para gerenciamento de produtos (cadastro, listagem e remoção) desenvolvida durante as aulas da **Generation Brasil**, além de exercícios práticos de fixação dos conceitos fundamentais de lógica de programação.

---

## 🚀 Funcionalidades do Projeto

1. **Bem-vindo ao Sacolão**: Uma interface interativa via console.
2. **Visualização de Estoque**: Exibição detalhada de produtos e seus respectivos preços de forma organizada utilizando formatação dinâmica de strings.
3. **Cadastro Interativo**: Permite ao usuário cadastrar novos produtos e valores com validação simples.
4. **Remoção Fácil**: Possibilidade de remover o último item cadastrado utilizando o conceito de pilha (`pop()`).
5. **Desafio FizzBuzz**: Algoritmo clássico de lógica de programação e divisibilidade de 1 a 100.

---

## 🛠️ Conceitos Práticos Aplicados

* **Entrada e Saída de Dados**: Utilização de `input()` e `print()` com f-strings para interação dinâmica.
* **Estruturas de Dados (Listas)**: Manipulação de dados com métodos como `.append()` e `.pop()`.
* **Estruturas de Repetição (Loops)**: Aplicação de `for` e uso avançado da função `zip()` para iterar de forma paralela por múltiplas listas.
* **Estruturas Condicionais**: Controle de fluxo com blocos `if`, `elif` e `else`.
* **Operadores Aritméticos e Lógicos**: Resolução do clássico problema matemático *FizzBuzz* com operadores de resto de divisão (`%`).

---

## 📂 Estrutura do Notebook

* **`etapa 1 a 3`**: Sistema de boas-vindas e exibição inicial dos produtos cadastrados.
* **`Revisão Geral`**: Variáveis simples (idade, altura), concatenação de textos e perguntas dinâmicas sobre pets.
* **`Verificador de Maioridade`**: Condicional simples para verificar se o usuário é maior de idade.
* **`Desafio FizzBuzz`**: Algoritmo otimizado para múltiplos de 3, 5 ou ambos.
* **`Gerenciamento de Inventário`**: Fluxo iterativo de inserção e deleção de produtos do Sacolão.

---

## 🖥️ Como Executar

1. Abra o arquivo no ambiente do **Google Colab**.
2. Execute as células sequencialmente (`Shift + Enter`).
3. Responda às perguntas interativas no console de execução para simular a compra, cadastro e remoção de produtos!
